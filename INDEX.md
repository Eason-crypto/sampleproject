# Project Index

## What this project does

This is a small example project that shows how a Python package can be organized and packaged. It includes a command-line entry point and a few simple math functions.

## Main Python code

- `src/sample/__init__.py` contains the command-line entry point.
- `src/sample/simple.py` contains the example functions.

## Tests

The tests are in `tests/test_simple.py`.

Run them from the project root with:

```bash
PYTHONPATH=src python3 -m unittest tests.test_simple
```

## Project rules

The project rules are in `AGENTS.md` in the project root.
